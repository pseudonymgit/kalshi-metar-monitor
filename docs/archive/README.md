# Documentation Archive

## Purpose

This archive preserves point-in-time documentation artifacts (audits, diagnostics, and milestone-era snapshots) that capture historical repository state for governance and traceability.

## Naming Convention

- Archive path: `docs/archive/YYYY-MM/`
- Keep original source filename when moved into archive.
- Month directory reflects archival month, not necessarily document creation date.

## Retention Rule

Historical audit documents must never be deleted from the archive.

## Immutability Rule

Archived documents must never be rewritten. If clarification is needed, add a new document outside archive (or a new archival entry) rather than editing archived content.
