## 4. Frozen Level Pipeline & Evaluation Budget

- **Level 0:** Sanity-check suite (3 evals: null-config, permutation, synthetic recovery) + sensitivity pre-screen (~30) + noise-floor estimation (5).
- **Level 1:** Per-parameter grid (~70 evals) — significant params only (5–8 of 22), 7-point coarse + 3-point refine; categoricals sweep all values.
- **Level 2:** Interaction & validation (~91 evals) — ±1-step validation (45), pairwise top-5 significant pairs (40), group meta-interaction (6).
- **Level 3 (conditional):** Bayesian optimization (~100 evals) — ONLY if Level 2 finds material interactions; restricted to interacting subgroup.
- **Level 4:** Walk-forward & robustness (~5 evals) — 3-window walk-forward, odd/even-year split, 5-seed robustness.

**Primary path total:** ~183 evals (no BO). **With BO escalation:** ~283.

## 5. Frozen Stopping Criteria

| Level | Stop / gate condition |
|---|---|
| Level 0 | All 3 sanity checks PASS + noise floor estimated; else STOP-FIX |
| Level 1 | All significant params swept + refined; insignificant frozen |
