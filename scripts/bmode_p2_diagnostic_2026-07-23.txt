2c — Halt file mechanism (COMPLETED)
  New file: scripts/halt_check.py
    - Checks for data/.halt before engine startup
    - Supports --write, --clear, --status CLI flags
    - Exit codes: 0 (halted), 1 (normal), 2 (error)
    - Writes timestamped reason string to halt file
    - Any abort condition can write the halt file to prevent execution

  Wired into: scripts/prod_paper_trading_cron.py
    - Added _check_halt_before_start() function
    - Called at the top of main() before any other initialization
    - If halt file exists, logs "HALTED" and exits 0
    - Graceful skip — no error, no retry, just silence

2d — Graceful degradation state machine (COMPLETED)
  New file: core/operation_state.py
    - States: NORMAL, WARN, DEGRADED, HALTED, EMERGENCY
    - Each state defines:
      - position_sizing_multiplier(): NORMAL=1.0, WARN=0.75, DEGRADED=0.50,
        HALTED=0.0, EMERGENCY=0.0
      - alert_intensity(): "normal", "elevated", "high", "minimal", "critical"
      - alert_throttle_multiplier(): 1.0, 1.5, 2.0, 0.2, 1.0
      - should_suppress_signal(signal_name, station): gates which signals run
      - position_sizing_cap(): max position as fraction of normal max
    - State transition validation: only allowed transitions are permitted
      (e.g., HALTED→EMERGENCY returns False)
    - Thread-safe _StateManager with history tracking (last 100 transitions)
    - Module-level singleton: get_state(), set_state(), get_state_summary()
    - Tested: All transitions, signal suppression, position sizing verified
